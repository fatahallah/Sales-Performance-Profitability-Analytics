SALES ANALYTICS PROJECT 01 — RAW DATA

Client: Retail & E-commerce Company
Period: 2024

Files:
Customers.csv
Products.csv
Sales_Reps.csv
Region_Targets.csv
Orders_YYYY-MM.csv (12 monthly raw order files)

IMPORTANT:
These are RAW client-style files. Do not clean them manually.
Some files contain intentional data-quality and formatting issues for investigation.

Start with DATA INVESTIGATION:
1. Identify table purpose.
2. Identify likely primary/foreign keys.
3. Check data types and data quality.
4. Determine relationships.
5. Decide which transformations are required.
6. Define business KPIs.

Do not jump directly to the dashboard.
